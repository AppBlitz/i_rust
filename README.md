# Installation rust on several operating system

This project aims to install Rust tools, including development tools. It supports Windows, Linux, and macOS.

This project arose from the need to use Rust on some of the most widely used operating systems, but previously, many steps were required depending on the operating system. This project aims to automate the entire process in a single step simply by running the project.
